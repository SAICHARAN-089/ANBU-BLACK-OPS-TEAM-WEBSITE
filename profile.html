Field Report Markup

The report works like a markup language. Start a line with a marker, and use inline formatting anywhere:

  • # text → main heading
  • ## text → deeper heading
  • $ text → second heading
  • <p> text → normal paragraph
  • - text → bullet point
  • 1. text → numbered list item
  • --- → horizontal rule
  • ![align|caption](image-url) → embedded image. Align: left, right, center, full. Example: ![left|Squad photo](data:image/png;base64,...)
  • Inline: **bold**, *italic*, `code`, [link](url)

Example — Naruto, dark theme:

# Naruto Uzumaki
$ The Shadow of the Leaf
<p> An ANBU legend forged in **darkness**.
- Shadow Clone Jutsu
- Rasengan
1. Survive the academy
2. Save the village
